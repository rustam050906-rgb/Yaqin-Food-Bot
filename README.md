# Yaqin Food — Telegram-бот с админ-панелью

## Структура проекта

```
yaqin-food-bot/
├── bot.py                 # логика бота (aiogram) — кнопка "Открыть каталог"
├── config.py               # ← сюда вставляете токен бота
├── requirements.txt         # зависимости бота
├── webapp/
│   └── index.html            # каталог/корзина/заказы/админ-панель (Web App)
└── backend/
    ├── main.py                 # сервер (FastAPI): пользователи, каталог, заказы
    └── requirements.txt        # зависимости сервера
```

Теперь у приложения 3 уровня доступа:
- **admin** — управляет каталогом (категории, товары, фото), пользователями (кто вообще может открыть бота), видит все заказы и может принять/отменить каждую позицию с причиной.
- **user** — видит только каталог и свои заказы. Доступ получает только тот, кого админ добавил по Telegram ID.
- **не зарегистрирован** — видит экран "Нет доступа".

Так как теперь данные общие для всех (а не только в телефоне одного человека), они хранятся на сервере (backend), а не в `localStorage`. Это значит бота больше нельзя просто открыть локально в PyCharm — нужен постоянно работающий сервер.

---

## Шаг 1. Разместить сервер (backend) на Render

1. Зайдите на https://render.com и зарегистрируйтесь (можно через GitHub).
2. Создайте GitHub-репозиторий (https://github.com/new), назовите как угодно, например `yaqin-food`. Git в терминале не нужен — на странице репозитория нажмите **"uploading an existing file"** и перетащите туда всю папку `yaqin-food-bot` (или содержимое этого архива).
3. В Render нажмите **New +** → **Web Service**, подключите этот GitHub-репозиторий.
4. Настройки сервиса:
   - **Root Directory**: `backend`
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: Free
5. Во вкладке **Environment** добавьте переменные:
   - `BOT_TOKEN` — тот же токен, что в `config.py`
   - `ADMIN_TELEGRAM_IDS` — ваш личный Telegram ID (чтобы вы сразу стали админом). Узнать свой ID: напишите что угодно боту **@userinfobot**, он пришлёт ID в ответ. Если админов несколько — перечислите через запятую: `111111111,222222222`
   - `DATABASE_URL` — см. шаг 2 ниже (без неё сервер работает на временной базе SQLite, и данные могут стереться при перезапуске — для реальной работы нужен шаг 2)
6. Нажмите **Create Web Service**. Через пару минут Render выдаст адрес вида `https://yaqin-food-xxxx.onrender.com` — это адрес вашего backend.

> Бесплатный тариф Render «засыпает» после 15 минут без запросов и просыпается ~30 секунд при следующем обращении — это нормально, не ошибка.

## Шаг 2. Постоянная база данных (Neon — бесплатно, без ограничения по времени)

1. Зайдите на https://neon.tech, зарегистрируйтесь, создайте проект.
2. Скопируйте **Connection string** (начинается с `postgresql://...`).
3. В Render, в переменных окружения вашего сервиса, добавьте `DATABASE_URL` = этот адрес и нажмите **Manual Deploy → Deploy latest commit**, чтобы применить.

## Шаг 3. Указать backend в веб-приложении

1. Откройте `webapp/index.html` в PyCharm.
2. В начале `<script>` найдите строку:
   ```js
   const API_BASE = "https://YOUR-BACKEND.onrender.com";
   ```
3. Замените на адрес из шага 1.6, например:
   ```js
   const API_BASE = "https://yaqin-food-xxxx.onrender.com";
   ```
4. Сохраните файл и загрузите его на ваш хостинг (Netlify/GitHub Pages) поверх старого — так же, как раньше.
5. (Необязательно, но удобно) В Render добавьте переменную `ADMIN_WEBAPP_URL` = адрес вашего webapp (например `https://ваш-сайт.netlify.app/index.html`) — тогда в уведомлении о новом заказе у админа будет кнопка «Открыть заказ», сразу ведущая в приложение.

## Шаг 4. Запустить бота (как раньше)

```bash
pip install -r requirements.txt
python bot.py
```

`config.py`:
```python
BOT_TOKEN = "ваш токен"
WEBAPP_URL = "https://ваш-сайт.netlify.app/index.html"
```

## Шаг 5. Добавить сотрудников

1. Откройте бота → «🛒 Открыть каталог» → иконка профиля (справа сверху) → **«Пользователи и доступ»** (видно только админу).
2. Попросите сотрудника написать что угодно боту **@userinfobot** — он пришлёт свой Telegram ID.
3. Введите ID, имя, заведение и позицию (Кухня/Бар/Гостиница и т.д.), нажмите «Добавить доступ».
4. Теперь этот человек может открыть бота и видит каталог — но не админ-функции.

## Как это работает дальше

- **Управление каталогом**: Профиль → «Управление каталогом» → категории и товары, фото через кнопку с камерой, переключатель «В наличии».
- **Новый заказ**: всем админам приходит сообщение в Telegram с деталями заказа.
- **Обработка заказа**: Заказы → открыть заказ → у каждой позиции кнопки «Принять» / «Отменить» (с указанием причины, например «нет на складе»). Статус всего заказа (Новый/В обработке/Выполнен/Отменён) меняется там же.
